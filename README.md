# mapswipe_leads
GeoJSON input data for MapSwipe projects


This repository contains GeoJSON input data for a MapSwipe projects.


## MapSwipe Daily Activity report

A daily report of tasks reviewed on MapSwipe and the top contributors, with a separate tab for TomTom projects:
**https://katarzynabaczewska-tomtom.github.io/mapswipe_leads/**

It is rebuilt every morning from [MapSwipe open data](https://mapswipe.org/en/data/) by the `MapSwipe daily report` workflow (Actions tab → *Run workflow* refreshes it on demand). The code is in [`report/`](report/).
